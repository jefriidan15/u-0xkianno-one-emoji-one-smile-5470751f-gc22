Entry for the **One Emoji, One Smile** competition: the program writes exactly
one emoji — 🥹 (face holding back tears, deeply touched and grateful) — and
nothing else to `/output/entry.txt`. Warm at first glance, universal, and
clearly chosen rather than the default smile.

Run it with Node 22+:

```sh
node main.ts
```
